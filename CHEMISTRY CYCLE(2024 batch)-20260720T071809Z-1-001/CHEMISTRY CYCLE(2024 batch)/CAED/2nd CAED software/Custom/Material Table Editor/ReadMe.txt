Program Name : MTBuilder.vbp
Last Modified: March 31, 2006

Description
-----------
This sample illustrates how to extract the material library from Solid Edge and populate an XLS file. The user can add new materials, deleted existing entries, or modify the existing values. The sample also has an import capability to take the contents of the XLS and add them back into the Solid Edge material library. The import will overrite all current Solid Edge materials, so appropraite backups should be made.

This program will require Solid Edge V19 and Microsoft Excel (R) to run.


Operation
---------
The program is a executable that will provide some commands for Export and Import. Follow the instrucions in the interface.
