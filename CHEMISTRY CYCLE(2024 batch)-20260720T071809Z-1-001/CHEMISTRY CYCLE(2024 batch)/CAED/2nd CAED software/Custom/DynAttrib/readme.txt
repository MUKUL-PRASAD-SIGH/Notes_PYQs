Program Name : DynAttrib.vbp (DynAttrib.exe)
Last Modified: June 14, 1999

Description
-----------
This program demonstrates using the Solid Edge Automation interface to read and write
dynamic attributes from a Solid Edge object.

To run this sample, Solid Edge must be running and a document of any type that contains
some graphics must be open.  Select an object (such as a feature of a part, or a part in an assembly), and then click "Get Attribute" to see attributes already associated with the object, or type an attribute value and click "Apply Attribute" to add the attribute to the selected object.
