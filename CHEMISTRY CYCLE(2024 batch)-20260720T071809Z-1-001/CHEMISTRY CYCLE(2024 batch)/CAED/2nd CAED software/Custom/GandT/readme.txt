Program Name : GandT.vbp (GandT.exe)
Last Modified: June 3, 1999

Description
-----------
This program demonstrates using the Solid Edge Automation interface to flatten a
sheetmetal part and then use the Geometry and Topology (G&T) portions of the Automation
interface to extract the edges of the flattened model.

The resulting 2d edges of the flattend model are written out to a file.
	C:\Temp\SEDump.txt

To run this sample, Solid Edge must be running and a sheet metal document containing a
part must be open.
