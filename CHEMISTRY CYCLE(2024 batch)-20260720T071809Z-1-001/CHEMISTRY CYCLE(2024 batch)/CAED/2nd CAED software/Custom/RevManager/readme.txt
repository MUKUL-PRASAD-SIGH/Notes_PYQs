Program Name : Revision Manager - Astruct.vbp (Astruct.exe)
Last Modified: September 22, 2000

Description
-----------
This sample program illustrates using the revision manager automation interface.  This sample uses the standalone revision manager server to nagivate through an assembly and displays the assembly components in the form.

This program is compiled as a stand alone executable and Solid Edge does not need to be running to use it.
