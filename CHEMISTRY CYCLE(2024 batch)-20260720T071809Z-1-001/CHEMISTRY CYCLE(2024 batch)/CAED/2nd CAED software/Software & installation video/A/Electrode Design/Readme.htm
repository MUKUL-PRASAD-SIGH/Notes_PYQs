Installing Solid Edge Electrode Design

Insert the Solid Edge DVD. Autorun should start automatically. Select "Other Solid Edge Products". Select "Mold Design". Select "Electrode Design". The InstallShield Wizard will guide you through the installation.

If Autorun does not start, you can double-click setup.exe located in the Electrode Design folder on the Solid Edge DVD.

You must install and remove Solid Edge Electrode Design from an account that has Administrator privileges. Solid Edge Electrode Design will run under User, Administrator, or Guest privileges.

Electrode Design is a 32-bit application and will only run on the 32-bit version of Solid Edge, which is the version available by default.

Running Solid Edge Electrode Design

To start using Electrode Design, make sure the Electrode Design toolbar is visible by checking if the Electrode Design Wizard option is selected in the View, Toolbars menu.

When there's no active electrode application's session, the only enabled command is the Create Project and Help commands. You can start a new session by starting the Create Project command. You must specify the folder where the current project will be stored and other general settings such as the default unit and default precision.

When the Create Project command ends, the Select Plate / Insert command starts automatically. With the Select Plate / Insert command you import the plate or insert where the electrode will work.

Uninstalling Solid Edge Electrode Design

Click the Add/Remove Programs on Control Panel. A list of products installed on your system will be presented. Select the Solid Edge Electrode Design entry and click the Remove button to begin the uninstall process.

Once you remove Solid Edge Electrode Design, be sure to reboot your system to ensure optimal operation from subsequent installations of Solid Edge Electrode Design.
