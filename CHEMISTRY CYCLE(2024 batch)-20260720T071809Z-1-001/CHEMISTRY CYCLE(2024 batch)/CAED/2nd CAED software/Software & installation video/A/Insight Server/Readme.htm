Description

Solid Edge Insight Server is a standalone product designed to be loaded on a SharePoint Server installation and is used to help manage Solid Edge data on the SharePoint Server. For more information about Solid Edge software and services, visit our home page on the World Wide Web at: http://www.solidedge.com.

Solid Edge Insight Server System Requirements and Information

 This release of Solid Edge Insight Server has been certified to run on the following:

  • Microsoft Windows 2003 Server, Standard or Enterprise Edition
  • Microsoft Windows SharePoint Services 2003 or Microsoft SharePoint Portal Server 2003
  • SQL Server 2000 or SQL Server 2005 running the latest SP

    Note: Version 20 is the last release that will support SQL Server 2000.

Refer to the Solid Edge Insight Implementation Guide for further Insight hardware system recommendations.

Installing Solid Edge Insight Server

The installed Solid Edge version and Insight Server version must be the same. That is, if you install Solid Edge version 20 on your client machines, then you must install Insight Server version 20 on your server.

You must install and remove Solid Edge Insight Server from an account that has Administrator privileges.

Insert the Solid Edge DVD. Autorun should start automatically. Click the "Other Solid Edge Products" button. Click "Insight Server". The InstallShield Wizard will guide you through the installation.

If Autorun does not automatically start, you can double-click setup.exe located in the Insight Server folder on the DVD.

No serial numbers are required to install this product.

Running Solid Edge Insight Server

Solid Edge Insight users are strongly encouraged to review the Insight Implementation Guide delivered with Solid Edge (Program Files\Solid Edge V20\Program\ResDLLs\0009\sespimpgde.chm).  This guide contains a wealth of information on installing and configuring SharePoint and Insight Server. Additionally it provides information that will aid in a successful experience in importing legacy  documents and creating new documents in the managed workspace. This document will be updated regularly with helpful hints, tips and techniques and posted to the Solid Edge  support web site: http://support.ugs.com/docs/solid-edge.html

The searchscope.txt document supports site entries in addition to document library entries. If you edit your searchscope.txt document to include a valid URL to a site, Insight will also use all valid Document Libraries in the Site. Validity includes presence of  Insight mandatory properties such as SELinkData.

EXAMPLE Site Entry: http://MySite

Document Libraries in this site - such as http://MySite/SolidEdgeDL1 and http://MySite/SolidEdgeDL2 will automatically be used by Insight.

To improve performance, you should limit the entries in the searchscope.txt to the minimum, since Insight will use every entry included in your searchscope.txt. In the previous example, if your searchscope.txt contains http://MySite, you would not want to include http://MySite/ SolidEdgeDL1 or http://MySite/SolidEdgeDL2 in your searchscope.txt.

You can also exclude a specific Document Library from being used by Insight, by including the keyword "Exception!".

EXAMPLE: Exception!http://MySite/SolidEdgeDL3

Uninstalling Solid Edge Insight Server

Click the Add/Remove Programs on Control Panel. A list of products installed on your system will be presented. Select the Solid Edge Insight Server entry, and click the Remove button to begin the uninstall process.

Once you remove Solid Edge Insight Server, be sure to reboot your system to ensure optimal operation from subsequent installations.
