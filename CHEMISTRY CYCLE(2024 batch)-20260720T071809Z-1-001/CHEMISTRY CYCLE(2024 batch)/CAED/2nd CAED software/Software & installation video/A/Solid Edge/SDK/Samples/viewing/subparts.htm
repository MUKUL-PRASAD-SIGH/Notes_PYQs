Publishing Using SolidEdge ActiveX

This is an example web page using the Solid Edge ActiveX viewer control, the Microsoft ActiveX ListBox control, and several standard HTML controls. All the controls are hooked together using VBScript.

Local Parts

 What Can I Do?
  • After selecting a part from the list box, select the Display button to load the part
  • The part viewer has a built in toolbar which can be turned on/off via the contol's ShowToolbar property. Use the Toolbar checkbox to interactively change this property.

 
 Toolbar
On/Off

The built-in toolbar will not be applicable to some applications. In this case, the ShowToolbar property would be set to False and the WEB application would implement specific commands as desired. There are five commands at the bottom of this page that demonstrate this capability. The OpenSE command is of special note as it will open the selected part in Solid Edge provided Solid Edge is loaded on the workstation, or using the standalone Solid Edge server.
