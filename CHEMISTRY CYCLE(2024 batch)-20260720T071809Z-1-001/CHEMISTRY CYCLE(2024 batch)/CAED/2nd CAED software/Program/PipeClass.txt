// This formatted file is used by the Solid Edge Piping command and is a means for
// the user to filter standard fittings during automatic placement. The fittings
// supported by automatic placement are gouped into "Classes" that define a
// search method for each of the fittings. The search criterion is applied on the
// Pipe fittings database in addition to other data from the Pipe command (such
// as nominal diameter, end treatments, fitting angles etc) to determine a unique
// fitting that would qualify for placement on the pipe route.
//
// Format Description
//
// - Lines that begin with // are not processed by Solid Edge and can be used for comments.
// - Each "Class" is defined between lines containing the tokens 'BeginClass' and 'EndClass'
// - The first line after 'BeginClass' is the name of the Class. This may be any string,
//   either recognized as common industry terminology or user defined name. This string will
//   be available for selecting the fitting class in the Pipe options dialog.
// - The line following the class name should start with STANDARDS. The words in quotes
//   following STANDARDS are the piping standards to which that class is applicable. A particular
//   class could be supported in multiple standards. For example, if definition of class ABC
//   is valid for ANSI and API the line should be - STANDARDS "API" "ANSI". Classes that
//   have assigned standards will be displayed in the Pipe options dialog when a listed
//   standard is selected.
// - Each of the fittings supported for placement by the Pipe command is listed in UPPER CASE
//   in the first column.
// - The second column defines the search method used. Currently only SIMPLE is supported
//   which uses the strings in the following columns to search in the Pipe fitting database. This
//   field enables support for more sophisticated search methods in the future. Entries in
//   this field must be in UPPER CASE. The quotes ("") at start and end of the string will
//   be removed prior to searching the database.
// - The third column is the Search Strings which are interpreted based on the search method
//   and are appropriately applied to the piping database. You may define multiple strings in
//   quotes and separated by spaces, like - "Class 25"	"Malleable". A fitting will be selected
//   which matches all the strings.
//
