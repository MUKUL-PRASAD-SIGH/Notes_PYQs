This directory contains sample image textures files and environment map
images.  The textures are divided into categories in separate directories.
The environment map images are contained under the env_maps directory.


CONTENTS

Default: Default images
   default.lwi: Default LightWorks image

Backgrounds library: Background and sky
   backgrounds/dome1.lwi: Sky image for applying to dome background
   backgrounds/dome2.lwi: Sky image for applying to dome background

   floors/cobbles.lwi: Cobblestones

   floors/floorbd2.lwi: Floorboards without nails
   floors/floorbd2b.lwi: A bump-map version of the above
   floors/fltile1.lwi: Terracotta tile with purple small squares

   floors/fltile4.lwi: Green marble tile with granite small squares

   floors/fltile6.lwi: Spotted terracotta tile with terracotta small squares

   floors/fltileb.lwi: A bump-map version of the above
   floors/greypave.lwi: Grey paving bricks in herringbone pattern
