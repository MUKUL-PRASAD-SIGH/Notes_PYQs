Building a Grinder Assembly in Solid Edge

This tutorial provides step-by-step instructions for creating an assembly of a hand-held grinder using traditional assembly relationships such as mate, axial align, and insert. It also demonstrates how you can pattern parts in an assembly and control the display of parts in an assembly.

This is an intermediate tutorial. You might find it easier to follow if you first complete the Introduction to Part Modeling tutorial.

Estimated time to complete: 20 minutes
