Modeling a Sheet Metal Part in the Context of an Assembly

This tutorial demonstrates a typical workflow for creating a sheet metal part within the context of a Solid Edge assembly. As you create this part, you will learn about creating parts in-place within assemblies and drawing profile geometry by including edges from other parts in an assembly.

This is an intermediate tutorial. You might find it easier to follow if you first complete the Introduction to Part Modeling or Introduction to Sheet Metal Modeling tutorials.

Estimated time to complete: 15 minutes
