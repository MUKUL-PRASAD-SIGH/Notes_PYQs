Creating a Wire Harness with Harness Design

This tutorial demonstrates a typical workflow for creating a wire harness with Harness Design. It provides step-by-step instructions for using Harness Wizard to automatically create a wire harness, creating harness conductors (wires, cables, and bundles), and moving wires.

This is an intermediate tutorial. You might find it easier to follow if you first complete the Introduction to Part Modeling tutorial.

Estimated time to complete: 30 minutes
