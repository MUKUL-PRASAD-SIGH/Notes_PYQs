Building a Family of Assemblies

This tutorial demonstrates a typical workflow for creating a family of assemblies with Solid Edge. It provides step-by-step instructions for creating a collection of similar assemblies within a single assembly document. As you work through this tutorial, you will learn about creating new family members, and the various techniques you can use to make the individual family members unique.

This is an intermediate tutorial. You might find it easier to follow if you first complete the Introduction to Part Modeling tutorial.

Estimated time to complete: 30 minutes
