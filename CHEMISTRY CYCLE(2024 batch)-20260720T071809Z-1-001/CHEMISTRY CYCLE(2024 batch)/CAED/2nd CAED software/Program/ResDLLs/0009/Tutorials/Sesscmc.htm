Modeling Contour Flanges in Solid Edge

This tutorial demonstrates a typical workflow for constructing contour flanges on a sheet metal part in Solid Edge. It provides step-by-step instructions for constructing different types of contour flanges.

This is an intermediate tutorial. You might find it easier to follow if you first complete the Introduction to Part Modeling or Introduction to Sheet Metal Modeling tutorials.
