Introduction to Sheet Metal Modeling

This tutorial demonstrates a typical workflow for creating a sheet metal part with Solid Edge. As you create this part, you will learn about constructing a base feature, flanges, contoured flanges, cutouts, and holes, and using precision drawing aids such as IntelliSketch.

This tutorial introduces basic concepts that other tutorials rely upon, so it is a good place to start if you are a beginner.

Estimated time to complete: 30 minutes
