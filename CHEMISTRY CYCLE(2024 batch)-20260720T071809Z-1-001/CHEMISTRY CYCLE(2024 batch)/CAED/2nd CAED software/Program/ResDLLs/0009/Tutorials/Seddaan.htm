Detailing Drawings with Solid Edge Draft

This tutorial demonstrates a typical workflow for creating a detailed drawing with Solid Edge. As you create this drawing, you will use techniques such as placing views, editing display properties, and placing dimensions and annotations.

This tutorial is for beginners, so you do not need prior experience with Solid Edge or any other computer-aided drafting or engineering modeling system to use it, but you might find this tutorial easier to follow if you first complete the Introduction to Part Modeling tutorial.

Estimated time to complete: 45 minutes
