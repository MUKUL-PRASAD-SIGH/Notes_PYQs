Building a Slider Assembly in Solid Edge

This tutorial provides step-by-step instructions for creating an assembly of a slider using the FlashFit option to apply positioning relationships between assembly components. The FlashFit option reduces the steps required to position a part using the traditional mate, planar align, or axial align relationships. This tutorial also demonstrates how to create and add subassemblies to an assembly.

This tutorial introduces basic assembly creation techniques. Although you do not need prior experience with Solid Edge to complete this tutorial, you might find it easier to follow if you first complete the Introduction to Part Modeling tutorial.

Estimated time to complete: 30 minutes
