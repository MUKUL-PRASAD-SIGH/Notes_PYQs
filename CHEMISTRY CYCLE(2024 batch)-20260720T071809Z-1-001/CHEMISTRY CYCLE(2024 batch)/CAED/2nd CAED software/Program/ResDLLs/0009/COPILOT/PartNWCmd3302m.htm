When you create a new part, the first step is to model a base feature, such as a Protrusion.

There are several types of Solid Edge documents: Assembly, Draft, Part, Sheet Metal, and Weldment. The New command creates a new document of one of these types.

The Introduction to Part Modeling tutorial provides a good overview of part modeling.

To save this part and return to the assembly, click Close and Return.

With the Assembly Select Tool, you can view the assembly and select other components to edit.
