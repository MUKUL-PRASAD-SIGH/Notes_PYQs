The first step in defining a flange is selecting an edge that the flange will join to.

For an explanation of what to do, follow the command prompts.

You can set options to control the bend radius, bend relief, and corner relief of each Flange feature individually, or leave the options set to use global values.

You can define whether the flange is created within or outside the starting edge.

If you don't want to model a flange, click the Cancel button or choose a different command.
