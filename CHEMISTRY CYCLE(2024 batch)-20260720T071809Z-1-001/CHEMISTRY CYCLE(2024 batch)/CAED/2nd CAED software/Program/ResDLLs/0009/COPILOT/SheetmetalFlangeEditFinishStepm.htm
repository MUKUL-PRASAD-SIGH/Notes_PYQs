To edit any of the steps you followed to create the flange, click the corresponding button on the SmartStep ribbon bar.

The elements you can click are dimensions and elements of the profile you see on the solid model.

Sometimes it is useful to rename features in ways that will help you find them later.

You can still edit the parameters you defined in earlier steps.

If you are done with this feature, click any other command you want to run -- you do not have to click Finish. Or click Finish to complete this flange and start another one.
