When you create a flange, the command provides a simple profile the length of the starting edge. You can redraw the shape of the flange.

For an explanation of what to do, follow the command prompts.

The Sketch/Plane Step has a specific set of options. Choose the best option for you from the SmartStep ribbon bar.

You can set the parameters for the flange now or while in the Profile step.

Choose a different command or click the Cancel button if you don't want to edit the flange.
