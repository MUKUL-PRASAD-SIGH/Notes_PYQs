The hole is completely defined now. Click any other command to continue modeling, and the hole will remain in your model.

The elements you can click are brightly colored elements you see on the solid model.

You can still go back and change what you did in previous steps.

Sometimes it is useful to rename features in ways that will help you find them later.

You can still change the hole parameters.

If you are done with this feature, click any other command you want to run -- you do not have to click Finish. Or click Finish to complete this hole and start another one.
