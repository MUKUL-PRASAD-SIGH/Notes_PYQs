You create Hole features in steps. The first step is either selecting a sketch that contains hole profiles or identifying a plane where you will draw a hole profile.

The Status Bar tells you what the command expects you to do next.

There are options for this step to let you identify a plane several different ways.

You can define the hole characteristics now or while you draw the hole profile.

If you don't want to model a hole, click the Cancel button or choose a different command.
