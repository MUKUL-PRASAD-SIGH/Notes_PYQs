The 2D Model environment allows you to draw your geometry at 1:1 scale without being confined by a drawing sheet.

Maintain Relationships places relationships as you draw so that the geometry elements remain associative to one another.  Use this option, for example, to keep adjacent lines connected to one another as you edit a sketch.

You can display or hide relationship handles while you draw associative geometry. Showing them lets you see and edit how geometry elements relate to each other.

The Creating 2D Drawings with Solid Edge tutorial provides a good overview of 2D drawing creation and constraints.
