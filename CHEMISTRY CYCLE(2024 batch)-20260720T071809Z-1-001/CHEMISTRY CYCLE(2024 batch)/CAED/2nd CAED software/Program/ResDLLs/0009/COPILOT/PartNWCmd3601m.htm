When you create a new sheet metal part, the first step is to model a base feature, such as a Tab.

The base feature may be a contour flange.

There are several types of Solid Edge documents: Assembly, Draft, Part, Sheet Metal, and Weldment. The New command creates a new document of one of these types.

The Modeling a Sheet Metal Bracket tutorial provides a good overview of sheet metal modeling.

To complete changes to this part, close the file and return to the parent assembly.
